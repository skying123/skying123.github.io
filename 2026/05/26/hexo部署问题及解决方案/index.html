Hexo 部署常见问题排查手册

整理时间：2026-05-18
适用环境：Hexo + Butterfly 主题 + GitHub Pages

一、本地搜索功能异常

1.1 问题：search.xml 文件过大导致推送后搜索功能失效

现象：

  • 本地 hexo s 搜索正常
  • 推送到 GitHub Pages 后，点击搜索框显示”数据库加载中”，无法正常搜索
  • search.xml 文件体积巨大（数 MB）

原因：

  • hexo-generator-search 插件生成的 XML 文件包含完整 HTML 内容，体积膨胀
  • GitHub Pages 对大型 XML 文件加载缓慢或超时
  • 部分 JS 压缩工具（如 babel）会破坏搜索脚本的解析逻辑

解决方案：

1.2 问题：搜索框一直显示”数据库加载中”

现象：

  • 点击搜索框后，下方持续显示”数据库加载中”
  • 无法弹出搜索结果
  • 浏览器 F12 Console 可能有 JS 报错

原因：

  • JS 压缩工具（如 babel）破坏了搜索脚本的执行逻辑
  • search.xml / search.json 文件路径错误或 404
  • GitHub Pages CDN 缓存未更新

解决方案：

  1. 检查 JS 压缩配置

    如果使用了 hexo-all-minifier 或主题内置压缩，将压缩器从 babel 改为 terser：

  1. 检查 search.json 是否成功生成
  1. 清除缓存并强制刷新

浏览器端按 Ctrl + F5 强制刷新。

  1. 等待 GitHub Pages 部署

    推送后等待 5-10 分钟，GitHub Pages 有部署延迟。

二、GitHub Pages 部署相关

2.1 问题：推送后网页未更新

现象：

  • hexo deploy 执行成功
  • 打开 GitHub Pages 网址，内容仍是旧版本

解决方案：

  1. 等待部署完成

    GitHub Pages 部署通常需要 1-10 分钟，大型站点可能更久。

  2. 强制刷新浏览器

    • Windows: Ctrl + F5
    • macOS: Cmd + Shift + R

  3. 检查仓库设置

    进入 GitHub 仓库 → Settings → Pages，确认：

    • Source 分支正确（通常为 gh-pages 或 main）
    • 自定义域名配置无误（如有）

  4. 确认部署分支

3.2 问题：hexo generate 报错

常见报错及解决：

报错信息 原因 解决方案
Template render error 文章 Markdown 语法错误 检查文章中的 {% %} 和 {{ }} 符号，用 &#123;&#123; 转义
Cannot find module 依赖缺失 npm install 安装缺失依赖
YAMLException _config.yml 格式错误 检查缩进，使用空格而非 Tab
FATAL Port 4000 has been used 端口被占用 hexo s -p 5000 更换端口

六、常用命令速查

命令 作用
hexo clean 清除缓存和已生成的文件
hexo generate / hexo g 生成静态文件
hexo server / hexo s 启动本地服务器

hexo new page "标题" 新建页面
