一、Allure 概述

1.1 什么是 Allure

Allure 是一个轻量级、灵活、多语言支持的测试报告框架，由 Qameta 团队开发。它从测试框架（如 Pytest、JUnit、TestNG）生成的原始数据中提取信息，生成交互式 HTML 报告。

1.2 核心优势

特性 说明
可视化 图表、趋势、时间线，一目了然
层级结构 Feature -> Story -> Test Case -> Step 四级嵌套
附件支持 截图、日志、视频、请求/响应体、任意文件
历史趋势 多次构建对比，自动标记 flaky test
多语言 Java/Python/JS/.NET/Go 等主流语言均有适配
CI/CD 友好 原生支持 Jenkins、GitHub Actions、GitLab CI

术语 含义 对应 Pytest
Feature 大功能模块 @allure.feature()
Story 用户故事/子功能 @allure.story()
Test Case 单个测试用例 def test_xxx():

Severity 严重级别 @allure.severity()
Attachment 附件 allure.attach()
Label 自定义标签 @allure.label()
Link 关联需求/缺陷链接 @allure.link()

十、面试高频问题

Q1：Allure 和 pytest-html 有什么区别？

维度 Allure pytest-html
交互性 强（图表、筛选、展开/折叠） 弱（静态表格）
趋势图 原生支持 不支持
附件类型 丰富（截图、视频、JSON、日志） 有限
CI/CD 集成 官方插件支持 Jenkins/GitHub/GitLab 需自行扩展
学习成本 中等 低
