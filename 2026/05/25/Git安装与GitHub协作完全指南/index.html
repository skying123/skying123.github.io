一、Git 安装

1.1 下载安装包

访问官网下载页面：https://git-scm.com/downloads

选择 Windows 版本下载。若下载较慢，可使用国内镜像（如 淘宝镜像）。

1.2 运行安装向导

双击下载的 .exe 文件，按以下建议配置：

步骤 推荐选项 说明
安装声明 直接点击 Next 进入下一步
组件选择 默认 + 勾选 Git Bash 保留 Git GUI 和 Git Bash，后者在 Windows 下非常好用
默认编辑器 Vim 或 VS Code 新手建议选 VS Code；想熟悉 Linux 可选 Vim
PATH 环境 Git from the command line and also from 3rd-party software 允许在 CMD、PowerShell 及第三方工具中使用 Git
HTTPS 后端 Use the OpenSSL library 通用兼容性好
行尾转换 Checkout Windows-style, commit Unix-style Windows 推荐，core.autocrlf=true，避免跨平台行尾问题
终端模拟器 Use MinTTY 支持 Unicode、自由调整窗口大小
额外选项 勾选 Enable file system caching 提升性能
实验功能 默认不勾选 稳定为主

点击 Install 完成安装。

三、从 0 开始创建 GitHub 仓库

本章节面向完全没有 GitHub 使用经验的用户，手把手教你从注册到创建第一个远程仓库。

3.1 注册 GitHub 账号

  1. 访问 https://github.com，点击 Sign up
  2. 输入邮箱、设置密码、填写用户名
  3. 完成邮箱验证（查收验证邮件并点击确认链接）
  4. 登录后建议开启双重认证（2FA）：点击头像 → Settings → Password and authentication → Enable two-factor authentication

注意：GitHub 已强制要求所有用户开启 2FA，否则部分功能受限。

3.2 在 GitHub 上创建新仓库

  1. 登录 GitHub，点击页面右上角 + 号，选择 New repository

  2. 填写仓库信息：

    • Repository name：仓库名称（如 my-first-project，只能包含字母、数字、连字符、下划线）
    • Description（可选）：项目描述
    • Visibility：
      • Public：公开，任何人可见（推荐开源项目）
      • Private：私有，仅你和授权协作者可见
    • Initialize this repository with：
      • ✅ Add a README file：添加 README 说明文件（推荐勾选）
      • ✅ Add .gitignore：选择项目类型（如 Node、Python、Java 等），自动忽略不需要版本控制的文件
      • Choose a license：选择开源协议（如 MIT、Apache-2.0）

  3. 点击 Create repository

  4. 创建成功后，你会看到类似这样的页面：

    页面会提供几种后续操作指引：

    • …or create a new repository on the command line：本地新建后推送
    • …or push an existing repository from the command line：本地已有仓库关联推送
    • …or import code from another repository：从其他平台导入

四、SSH 密钥与账号管理

GitHub 已于 2021 年底停止支持密码验证 HTTPS 推送，现在推荐使用 SSH 密钥 或 Personal Access Token (PAT) 进行身份验证。

4.1 方案一：SSH 密钥（推荐）

SSH 密钥配置完成后，无需每次输入密码，是最便捷的长期方案。

4.1.1 检查是否已有 SSH 密钥

打开 Git Bash 或 PowerShell，输入：

如果看到 id_ed25519 和 id_ed25519.pub（或 id_rsa 和 id_rsa.pub），说明已有密钥，可跳到 4.1.3 步。

4.1.2 生成新的 SSH 密钥

在 Git Bash 中执行：

按提示操作：

  1. Enter file in which to save the key：直接回车，使用默认路径 C:\Users\你的用户名\.ssh\id_ed25519
  2. Enter passphrase：设置密钥密码（可选，直接回车表示不设置，个人电脑推荐不设置）
  3. Enter same passphrase again：再次确认密码

生成成功后，会在 ~/.ssh/ 目录下产生两个文件：

  • id_ed25519：私钥，绝对不能泄露
  • id_ed25519.pub：公钥，需要上传到 GitHub

4.2 方案二：Personal Access Token (PAT)

如果你暂时不想配置 SSH，或者需要在某些不支持 SSH 的场景（如 CI/CD、脚本）中使用，可以使用 PAT。

4.2.1 生成 PAT

  1. 登录 GitHub，点击头像 → Settings → 左侧最下方 Developer settings
  2. 选择 Personal access tokens → Tokens (classic)
  3. 点击 Generate new token (classic)

  4. 填写信息：

    • Note：令牌名称（如 My Laptop Git）
    • Expiration：有效期（可选 30 天、90 天、1 年或自定义）
    • Scopes：勾选权限，至少需要：
      • ✅ repo：完全控制私有仓库
      • ✅ workflow：管理 GitHub Actions
      • ✅ read:org：读取组织信息（如需要）

  5. 点击 Generate token

  6. 立即复制显示的令牌（只显示一次，刷新页面后不可再见）

4.2.2 使用 PAT 进行 Git 操作

使用 HTTPS 地址克隆或推送时，Git 会要求输入密码，此时：

  • Username：你的 GitHub 用户名
  • Password：粘贴刚才生成的 PAT（不是你的 GitHub 登录密码）

十、常用命令速查表

命令 作用
git init 初始化本地仓库
git clone <url> 克隆远程仓库
git status 查看文件状态
git add <file> 添加文件到暂存区
git add . 添加所有修改
git commit -m "msg" 提交更改
git push 推送到远程
git pull 拉取并合并远程更新
git fetch 获取远程更新（不合并）
git branch 查看本地分支
git branch -a 查看所有分支
git checkout -b <name> 创建并切换分支
git switch -c <name> 创建并切换分支（新命令）
git merge <branch> 合并分支
git log --oneline 查看简洁提交历史
git log --graph 图形化显示分支历史
git reset --soft HEAD~1 撤销最近一次提交（保留修改）
git reset --hard <id> 硬回退到指定版本（丢弃修改）
git reflog 查看所有操作记录
git stash 临时保存修改
git stash pop 恢复最近一次 stash
git diff 查看文件差异
git blame <file> 查看文件逐行归属
git tag -a v1.0 -m "msg" 创建附注标签
git remote -v 查看远程仓库地址
git remote add origin <url> 关联远程仓库
git remote set-url origin <url> 修改远程仓库地址

结语

Git 的学习曲线主要集中在分支模型和冲突解决上。建议新手按照以下路径学习：

  1. 第 1 周：熟悉 add → commit → push → pull 基础循环
  2. 第 2 周：掌握分支创建、切换、合并
  3. 第 3 周：尝试解决一次合并冲突
  4. 第 4 周：参与团队协作或开源贡献（Fork + PR 模式）

如需图形化工具辅助，Windows 用户可尝试 GitHub Desktop、SourceTree 或 GitKraken，但建议先熟悉命令行，这对理解 Git 原理和排查问题至关重要。
